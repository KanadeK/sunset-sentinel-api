# Security Policy

## Supported version

Security fixes are provided for the latest `0.1.x` release while the project is in alpha.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for this repository. Do not open a public
issue with secrets, internal URLs, or exploit details. Include the affected version, a minimal
reproduction, impact, and suggested mitigation when available.

The project rejects URL credentials, applies an explicit domain allowlist to network scans,
redacts sensitive query values from output, and keeps the bundled demonstration offline.
