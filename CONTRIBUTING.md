# Contributing

Thank you for helping improve Sunset Sentinel API.

1. Open an issue that describes the user impact and proposed behavior.
2. Create a focused branch from `main`.
3. Install Python 3.12 dependencies with `python -m pip install -e ".[dev]"`.
4. Add tests for successful, boundary, and failure behavior.
5. Run `python scripts/verify.py` before opening a pull request.

Do not include production credentials, private API responses, customer identifiers, or
unlicensed fixtures. Commits must use the contributor's own identity and must not add automated
co-author trailers.
